首页 / 应用实践 / 快速定位问题

调试是排除法——信息越清晰、排除掉的可能性越多，找到问题就越快。本文给出与「参考实现」对齐的系统化调试方法，重点解决一个实际问题：怎么避免在可疑但不正确的路径上越钻越深。

一、核心原则：证据高于假设

把每一条信息分类，绝不含糊：

标签 含义 纪律
[FACT] 直接观测到（日志、报错、复现、代码行） 使用前注明出处
[HYPOTHESIS] 你的推断 必须标注，不得当事实陈述
[UNKNOWN] 还不知道的 决定下一个要查/要问的问题

说不出来源的结论一律是 [HYPOTHESIS]。这一条是「不深入错误路径」的地基——分不清事实与猜测，就会把猜测当路标。

二、六步流程

Step 0：评估已知信息

把已知信息过一遍：错误/日志、复现步骤、环境、最近变更、出现频率、受影响模块。分类为 [KNOWN]（直接用）/ [NEEDED]（影响复现，先问用户）/ [WEAK]（标记后继续）。

Step 1：探索代码（只查结构，不深挖）

用 explorer 子代理快速摸清：受影响模块、最近变更、堆栈函数。目标是代码结构与数据流，不是细节——细节留给缩小路径之后的步骤。这一步还顺带省 token（过程不占主上下文）。

Step 2：复现或收集证据

能复现就记录准确条件；不能复现就收集最强的间接证据（日志、监控）。始终区分事实与推测。

Step 3：缩小到最小路径

  • 二分法排除：禁用一半链路，看症状是否消失；
  • 输入最小化：仍然失败的最简单输入；
  • 变量隔离：一次只改一个东西；
  • 明确写出排除了什么——否定性结论同样有价值。

目标：具体的函数或行，而不是模糊的模块。

Step 4：区分症状与根本原因

  1. 移除这段逻辑，症状是否消失？（因果关系检查）
  2. 这个错误是结果还是原因？（NPE 是症状，上游空值是根因）
  3. 向上追踪：最早在哪里出错？

根因 = 修它就能消除症状。 证不了因果，就还只是 [HYPOTHESIS]。

Step 5：最小化修复

修根因、不修症状；只做必要的改动；检查边界情况与正常路径。

Step 6：验证修复

复现场景通过了吗？相关测试有没有回归？共享代码的调用方呢？换个条件会不会再坏？

三、卡壳协议：觉得不对，先停

这是本文最重要的部分。在错误路径上「再挖深一点」是最贵的操作——它烧时间、烧 token，还制造「快要找到了」的错觉。

满足任意一条即视为卡住：

  • 连续 2+ 轮探索没有获得新的 [FACT]；
  • 缩小范围后信心仍未上升（停在低信心）；
  • 不断产生 [HYPOTHESIS] 却无法用证据确认任何一个；
  • 重复检查同一区域，却没有排除任何新可能。

卡住时——停止深挖，按下面四步做：

  1. 总结已经排除了什么（否定性结论有价值，别丢）；
  2. 列出阻塞你的具体 [UNKNOWN]——要具体到「我需要触发 500 的那个请求体」，而不是「需要更多信息」；
  3. 说明没有用户输入你无法判断什么；
  4. 不要在同方向继续猜；不要把未证实的假设当根因继续往下做。先穷举其他可能性，实在不行再回头深入。

配套纪律（与 TUI 行为一致）：

  • 信心分级递进：低 → 中 → 高；没排除替代方案就跳到「高」，警惕确认偏差；
  • 失败即停：同一操作连续失败 3 次，停止重试并上报阻塞（Fail forward）；
  • 先穷举、后深入：优先用低成本实验（读日志、二分、最小复现）排除整类可能，而不是押注一条路径深挖。

四、和省 token 的关系

上述策略本身就是省 token 的调试法：

做法 省在哪
explorer 先摸结构 探索过程不进主上下文
二分/最小复现 用最少轮次排除最多可能
失败 3 次即停 不重复烧无效轮次
卡壳上报（带具体 UNKNOWN） 把不确定性交给最廉价的信源——人
长测试进后台 输出落盘，不占对话

五、一个小例子

现象：接口偶发 500。

Step 0  [KNOWN] 发生频率约 1/50；[NEEDED] 请求体样本、发生时间段 → 先要样本
Step 1  explorer：定位 handler → service → 存储层调用链（只看结构）
Step 2  拿到样本，本地 100 次压测复现 2 次 → [FACT] 与并发相关
Step 3  二分：关掉缓存层后不再复现 → 排除业务逻辑，锁定缓存层
Step 4  缓存层读到了过期 null 值 → 与症状存在因果链 → [FACT] 根因
Step 5  最小修复：缓存空值不写占位
Step 6  复测 200 次通过；相关单测回归通过

每一步都有「发现/已排除/信心」的推进感；如果 Step 3 两轮都没有新事实——触发卡壳协议，停止深挖，带着「已排除清单 + 具体 UNKNOWN」找人。
