首页 / 附录 / 命令速查

本页以仓库实际文件为准：斜杠命令来自 .opencode/command/*.md（45 个），CLI 命令来自 bin/opencode wrapper 与 init.sh。TUI 内输入 / 会弹出全部列表；$ARGUMENTS 表示命令后可跟参数。

一、斜杠命令（TUI 内）

基础与信息

命令 用途 示例
/docs <主题> 打开 opencode 官方文档 /docs agents
/settings 查看当前配置（模型 / 权限 / 上下文 / 技能数） /settings
/context 查看当前上下文快照 /context
/secrets 查看已配置密钥 / 配置指引 /secrets
/plugins <操作> 查看 / 管理插件与 MCP 状态 /plugins list
/debug-harness 运行时诊断（git / 目录 / 任务状态） /debug-harness
/reload 刷新配置与技能 /reload
/btw <问题> 顺带问小事（探索子代理，不打断主对话） /btw 配置在哪加载
/cancel 取消当前操作 /cancel
/copy 复制最后一条回复 /copy

计划、任务与知识

命令 用途 示例
/plan <目标> 进入计划模式（先分析后实施） /plan 重构认证模块
/plan_checkout [路径] 加载已有计划文件并进入 plan 模式 /plan_checkout plans/x.md
/run 执行当前计划 /run
/todo 管理 todos（查看 / 创建 / 更新） /todo 列出现有 todo
/tasks 查看 / 管理后台任务 /tasks list
/loop <cron> <内容> 创建定时提醒 /loop "0 9 * * *" 提醒提交工时
/memory <操作> 查看 / 编辑自动记忆 /memory list
/workscene <操作> 场景知识库（reference 检索 / 归档） /workscene find 老化测试
/learn 把会话中的非显然经验写入 AGENTS.md /learn

上下文与会话

命令 用途 示例
/compact 压缩上下文（保留近期原文） /compact
/compact_run <计划> 先压缩上下文再执行计划 /compact_run 重构后跑测试
/clear 清空上下文（仅保留记忆与要点） /clear

开发与协作

命令 用途 示例
/commit git 提交并推送（含规范前缀） /commit
/rmslop 对比 dev 分支移除 AI 生成的 slop /rmslop
/spellcheck 对 markdown 改动做拼写检查 /spellcheck
/changelog 从结构化输入生成 UPCOMING_CHANGELOG.md /changelog
/issues <关键词> 查找 GitHub issue /issues auth bug
/ai-deps 检查 AI SDK 依赖可升级版本（minor/patch） /ai-deps
/translate <文本> 翻译成其他语言 /translate hello
/feedback <内容> 提交使用反馈（可上报远程） /feedback 建议…

项目初始化

命令 用途 示例
/init [目录] 初始化项目级 .opencode/ 目录结构 /init .

子代理

命令 用途 示例
/sa 列出可委派子代理 / 委派任务 /sa、@explore 搜索 xxx
/subagent 同 /sa（列出子代理并委派） /subagent

Jira

命令 用途 示例
/jira_get_issue <issue-key> 读取 Issue 详情（含变更历史） /jira_get_issue PROJ-123
/jira_new_issue [project] [summary] [desc] 新建缺陷 / 子缺陷 /jira_new_issue 登录超时
/jira_new_task [project] [summary] [desc] 新建任务 / 子任务 /jira_new_task 修复导出

Gerrit

命令 用途 示例
/gerrit_search_changes <query> [--limit N] 搜索变更（支持完整 query 语法） /gerrit_search_changes message:登录 status:open
/gerrit_get_change <change-number> 查看变更详情（commit message + 文件列表） /gerrit_get_change 1899234
/gerrit_get_file <project> <path> [--branch BRANCH] 浏览仓库文件（自动 clone） /gerrit_get_file Monitor/x/src src/main.c
/gerrit_search_code <project> <pattern> [--branch] [--ignore-case] [--max-results N] 代码搜索（git grep） /gerrit_search_code Monitor/x DDR_Init

KB（Confluence）

命令 用途 示例
/kb_search <query> 搜索知识库页面 /kb_search 老化测试
/kb_get_page <page-id> 查看页面详情（含正文） /kb_get_page 12345678
/kb_create_page [space] [title] [content] 创建新页面 /kb_create_page KB 新页 <p>正文</p>

飞书表格

命令 用途 示例
/feishu_sheet_list <wiki_url> 列出飞书 wiki 表格的全部 sheet /feishu_sheet_list <wiki_url>
/feishu_sheet_read <wiki_url> [sheet名] [--latest-only] 读取指定 sheet 内容（支持版本过滤） /feishu_sheet_read <wiki_url> Sheet1

常用别名：/jgi（jira_get）、/jni（jira_new_issue）、/jnt（jira_new_task）、/gsc（gerrit_search_changes）、/ggc（gerrit_get_change）、/ggf（gerrit_get_file）、/gscode（gerrit_search_code）、/kbs（kb_search）、/kbg（kb_get_page）、/kbc（kb_create_page）、/fsl（feishu_sheet_list）、/fsr（feishu_sheet_read）。

说明： - jira / gerrit / kb / 飞书表格命令已内置在 .opencode/command/；实际执行由 jira-cli / gerrit-cli / kb-cli / feishu-sheet 技能（随插件资产分发）完成，凭据配在 ~/.config/secrets.env。未安装对应插件资产时命令可见但会因缺技能/凭据失败。 - /help、/agent <名称> 等由 opencode 内置提供，不属于本仓库命令文件。

二、CLI 命令（TUI 外 / 脚本 / 自动化）

启动与运行

命令 用途
opencode [目录] 启动 TUI（默认当前项目）
opencode -c / --continue 继续上次会话
opencode -s <id> / --session 继续指定会话
opencode --fork 继续时派生新会话
opencode -m <provider/model> 指定模型
opencode --agent <名称> 指定代理
opencode --prompt <文本> 附带初始 prompt
opencode --auto 自动批准未被显式拒绝的权限
opencode run "<任务>" 非交互执行任务
opencode run -f <文件> --format json 附加文件 / JSON 事件输出（脚本解析）
opencode serve [--port N] [--hostname H] [--cors 源] 启动服务端（供 web / 飞书桥接）
opencode attach [-u <user> -p <pass>] 附加到运行中的 serve

初始化与维护

命令 用途
opencode init 全局初始化（等价 ./init.sh）
opencode init --build 初始化并重编译定制版二进制
opencode init --force 重建 opencode.json（自动保留私有配置并备份）
opencode init --reset 完全初始化（清空非 git 私有内容，先备份到 /tmp）
opencode init --backup / --restore <tar.gz> 备份 / 还原私有配置
opencode init-project [目录] 在项目目录创建 .opencode/ 骨架
opencode auth login [-p <provider>] 登录 provider 认证
opencode models [--refresh] 查看 / 刷新模型列表
opencode upgrade 升级（定制版请用 git pull && opencode init --build）
opencode uninstall [--keep-config --keep-data] 卸载

会话与诊断

命令 用途
opencode session [--max-count N] 会话管理（table / json）
opencode stats [--days N] 使用统计
opencode export [--sanitize] 导出会话（可脱敏）
opencode mcp / opencode plugin [-g\|-f] MCP / 插件管理
opencode debug config 诊断配置（确认 apiKey 解析、provider 列表）
opencode --print-logs / --log-level DEBUG 详细日志

底层等价：./init.sh --build = 手动 cd packages/opencode && bun run build --single；产物 packages/opencode/dist/opencode-linux-x64/bin/opencode 自动 symlink 到 ~/.local/bin/opencode。

三、本地 wrapper 命令（bin/，不经过 LLM）

init.sh 会把这些 CLI 写到 ~/.config/opencode/bin/（已在 PATH 中），可直接在终端调用：

命令 用途
asset list/pull/setup/run/push/status/info/new/export 资产管理（@agent/@skill/@tool/@launcher/@plugin）
plan init/write/sub/status/run/update 计划引擎（四层规划 + DAG 子计划）
privacy scan/git/mask/words 隐私扫描 / 脱敏 / 敏感词管理
skill-usage list/clear 技能使用统计
usage-stats list/clear 工具使用统计
tool-usage list/summary 工具调用记录
session-search <关键词> / list 历史会话搜索
feishu-notify send "<内容>" [--title 标题] 经 oc-lark 发飞书通知
publish-assets 资产发布（meta 校验 + 隐私扫描 + 推送）
init-project [目录] 项目级 .opencode/ 初始化

这些工具同时以自定义工具形式暴露给 Agent，对话中可直接让 AI 调用（如「用 plan 建个计划」「后台跑构建」）。
