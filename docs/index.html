本仓库是 opencode 团队定制版：在上游 opencode 的基础上，提供一套开箱即用的运行时配置层（.opencode/）——子代理、技能、自定义工具、斜杠命令、工作流、评估、工作场景与配套的全局初始化脚本（init.sh）。

目标：把团队日常开发所需的 Agent 能力沉淀为可分发、可复用、可度量的配置资产，并对齐内部「参考实现」Agent 运行时的使用体验。

文档中出现的「参考实现」= 团队内部 Agent 运行时（对标对象）。定制版在保持 opencode 原生优势的前提下，逐项对齐其能力；对照说明见 能力对照说明。

快速开始

# 1. 新机器（拉取仓库 + 部署全局配置）
curl -fsSL https://raw.githubusercontent.com/Wyili/opencode/dev/bootstrap.sh | bash

# 2. 已有仓库（等价 opencode init）
cd ~/opencode && ./init.sh && source ~/.bashrc

# 3. 启动会话
opencode

# 4. 项目内初始化（在任意项目目录创建项目级 .opencode/）
opencode init-project
