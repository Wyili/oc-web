首页 / 快速上手 / 启动与界面

启动 TUI 只需在项目目录敲 opencode。日常操作都围绕三件事：发指令、切模型/代理、管会话与上下文——本文把这三条的入口（命令、快捷键、参数）集中到一张张速查表。

一、启动方式

场景 命令
启动 TUI（当前项目） opencode
指定项目目录 opencode <项目目录>
继续上次会话 opencode -c / --continue
继续指定会话 opencode -s <id> / --session <id>
继续时派生新会话 opencode -c --fork
指定模型 / 代理 opencode -m <provider/model> / --agent <名称>
附带初始 prompt opencode --prompt "<文本>"
自动批准权限 opencode --auto
非交互执行 opencode run "任务描述"
启动服务端（headless，供 API / 桥接） opencode serve
启动服务端并打开 Web 界面 opencode web

运行中输入 / 自动弹出命令列表；不确定有什么命令就敲 /。/help 看帮助与快捷键，/docs <主题> 打开官方文档（agents/skills/plugins/mcp/keybinds）。

二、斜杠命令速查

TUI 内输入 / 弹出全部命令（本仓库共 40+ 个，完整清单见 命令速查）。

三、快捷键

TUI 内默认键位（可在 ~/.config/opencode/tui.json 自定义；leader 默认 Ctrl+X）：

操作 默认键位
切换主代理 Tab / Shift+Tab
命令列表 Ctrl+P
新会话 <leader>n
会话列表 / 切换 <leader>l
切换模型 <leader>m（即 Ctrl+X m）
循环最近模型 F2 / Shift+F2
中断当前任务 Escape
压缩上下文 <leader>c
复制消息 <leader>y
导出会话 <leader>x
打开编辑器 <leader>e
切换侧边栏 <leader>b

四、会话管理

操作 入口
新建会话 <leader>n 或 opencode
会话列表 / 切换 <leader>l / opencode session [--max-count N]
继续上次会话 opencode -c
继续指定会话 opencode -s <id>（--fork 派生新会话）
中断当前任务 Escape
导出会话（可脱敏） <leader>x / opencode export [--sanitize]
使用统计 opencode stats [--days N]

会话数据库会自动清理（OPENCODE_EVENT_CLEANUP=1 由 init.sh 写入：保留 30 天 / 上限 500MB），避免 event 表膨胀。

五、切换模型

方式 操作
模型选择器 <leader>m（Ctrl+X m）；F2 / Shift+F2 循环最近模型
启动时指定 opencode -m <provider>/<model>
会话内切换 选择器面板（model_picker / model_tabs 在 tui.json 配置）
列出可用模型 opencode models [--refresh]
永久默认 改 opencode.json 的 model / small_model

小模型（small_model）用于标题生成、压缩等轻任务；子代理可在 frontmatter 写 model: small 直接复用同一档（explorer 已默认挂载）。详见 模型配置。

六、权限模型

opencode 的权限按工具声明，每个工具取 ask（询问）/ allow（直接允许）/ deny（拒绝），写在 opencode.json 的 permission 字段：

{
  "permission": {
    "edit": "allow",
    "bash": "ask",
    "webfetch": "ask"
  }
}
  • 可整体给一个值："permission": "ask" 等价于对所有工具生效（"*": "ask"）；
  • 常用键：read / edit / glob / grep / list / bash / task / webfetch / websearch / lsp / skill 等；
  • 启动参数 opencode --auto 自动批准未被显式拒绝的权限（危险，谨慎使用）。

内部「参考实现」用 approval_mode 暴露四个预设（strict / balanced / accept_edits / trust）。opencode 定制版没有同名预设开关，而是用上面的工具级规则表达等价效果——例如「平衡」≈ 常见工具 allow、危险操作 ask。

七、上下文与压缩

操作 入口
压缩上下文（保留近期 token） <leader>c 或 /compact
查看上下文快照 /context
清空上下文（仅记忆） /clear
压缩策略配置 opencode.json → compaction（auto / tail_turns / preserve_recent_tokens / reserved）

长会话不压缩会持续重发旧历史；换任务尽量 /new（或 <leader>n），原理见 省 token 与上下文管理。
